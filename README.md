# SE4050 – Deep Learning Lab 4

## Application of Convolutional Neural Networks – Part 1

This repository contains the work completed for **Lab Exercise 4** of the **SE4050 – Deep Learning** module.

### Objective

The objective of this lab is to apply Convolutional Neural Networks (CNNs) to a **Siamese Network-based face recognition and verification task**.

### Lab Tasks

The lab includes the following activities:

1. Load the Face Recognition notebook into Google Colab.
2. Set up the required Python files:
   - `fr_utils.py`
   - `inception_blocks_v2.py`
3. Set up the required image dataset.
4. Load the pre-trained model weights.
5. Run the face recognition notebook.
6. Add a new individual's image to the face recognition database.
7. Perform:
   - Face verification
   - Face recognition
8. Analyze the L2 distances between the test image and database face embeddings.
